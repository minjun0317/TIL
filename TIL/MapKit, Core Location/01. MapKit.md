# MapKit
➡️ 앱 안에 지도 띄우고, 그 위에 장소 표시하거나 길찾기, 장소 검색 같은 거 할 수 있게 해주는 애플 프레임워크

## 언제 씀
- 가게, 매장 위치 지도에 보여줄 때 (배달앱, 카페 찾기 이런거)
- 내 주변 장소 핀으로 찍어서 보여줄 때
- 출발지 → 도착지 경로 그릴 때 (`MKDirections`)
- "카페" 같은 키워드로 근처 장소 검색할 때 (`MKLocalSearch`)

## 지도 앱에서 MapKit이 하는 일
지도 앱을 쪼개보면 크게 두 개임
1. 내가 지금 어디있는지 알아내기
2. 그걸 지도에 그려서 보여주기

MapKit은 **2번 담당**임. 지도 타일 그리기, 확대/축소, 드래그, 핀 찍기, 경로 선 그리기 같은 **보여주는 쪽** 일을 다 함

1번(위치 알아내기)은 Core Location이 함 → [02. Core Location](./02.%20Core%20Location.md) 에서 정리함

# MKMapView
➡️ UIKit에서 쓰는 지도 뷰. `UIView` 상속받은 애라서 UIKit 화면에 그냥 붙이면 됨

```swift
import MapKit

let mapView = MKMapView()
mapView.showsUserLocation = true   // 내 위치 파란점 표시
view.addSubview(mapView)
```

- 핀 커스텀하거나 탭 이벤트 받으려면 `MKMapViewDelegate` 써야함
- SwiftUI 나오기 전부터 있던 애라 자료 제일 많음
- SwiftUI에서 쓰려면 `UIViewRepresentable`로 감싸야함

.

# SwiftUI의 Map
➡️ SwiftUI 전용 지도 뷰. 뷰 하나로 끝나서 MKMapView보다 훨씬 간단함

```swift
import SwiftUI
import MapKit

struct ContentView: View {
    var body: some View {
        Map {
            Marker("서울시청", coordinate: CLLocationCoordinate2D(latitude: 37.5665, longitude: 126.9780))
        }
    }
}
```

- iOS 17부터 `Map { }` 안에 Marker, Annotation 같은거 바로 넣는 방식으로 바뀜
- 그 전에는 `Map(coordinateRegion: $region)` 이렇게 썼는데 이건 지금 deprecated 됨. 구글링하면 옛날 코드 많이 나와서 헷갈리니까 주의
- 카메라 위치(어디 보여줄지)는 `MapCameraPosition`으로 관리함

| **MKMapView vs Map**

| | MKMapView | Map |
|---|---|---|
| 프레임워크 | UIKit | SwiftUI |
| 코드량 | 많음 (delegate 필요) | 적음 |
| 커스텀 | 거의 다 됨 | 아직 안 되는거 좀 있음 |

# CLLocationCoordinate2D
➡️ 위도, 경도 두 개 묶어놓은 구조체. **지구 위 한 점**을 나타냄

```swift
let cityHall = CLLocationCoordinate2D(latitude: 37.5665, longitude: 126.9780)
```

- 이름이 CL로 시작하는거 보면 알 수 있듯이 원래 **Core Location** 소속임
- 근데 MapKit에서도 좌표 쓸 때 이거 그대로 씀 (MapKit이 Core Location을 가져다 쓰는 구조)
- 값은 `Double` (정확히는 `CLLocationDegrees` 인데 이게 Double 별칭임)

## 위도 (latitude)
- 적도 기준으로 **위아래(남북)** 얼마나 떨어졌는지
- 범위 : -90 ~ 90
- 적도 0, 북극 90, 남극 -90
- 한국은 북반구라 대충 33 ~ 38 사이

## 경도 (longitude)
- 영국 그리니치 천문대 기준으로 **좌우(동서)** 얼마나 떨어졌는지
- 범위 : -180 ~ 180
- 동쪽이 +, 서쪽이 -
- 한국은 대충 126 ~ 130 사이

👉 외우는 법 : 위도는 **가로줄**인데 **위아래** 위치를 나타내고, 경도는 **세로줄**인데 **좌우** 위치를 나타냄. 줄 방향이랑 의미가 반대라서 처음에 계속 헷갈렸음

⚠️ 순서 주의 : 위도, 경도 순서임. 구글맵에서 좌표 복사하면 `37.xx, 126.xx` 이렇게 위도가 먼저 나옴. 순서 바꿔 넣으면 남극 근처 바다로 감

# MKCoordinateRegion
➡️ 지도에서 **어디를, 얼마나 넓게** 보여줄지 정하는 구조체

```swift
let region = MKCoordinateRegion(
    center: CLLocationCoordinate2D(latitude: 37.5665, longitude: 126.9780),
    span: MKCoordinateSpan(latitudeDelta: 0.01, longitudeDelta: 0.01)
)
```

`center` + `span` 두 개로 이루어짐

## region
- 지도 화면에 **지금 보이는 사각형 영역** 이라고 생각하면 됨
- 사용자가 지도 드래그하거나 확대하면 region이 계속 바뀜
- 앱 처음 켰을 때 어디 보여줄지 정할 때 이거 씀

## center
- 그 영역의 **가운데 좌표**

## span
- 그 영역이 **얼마나 넓은지** = 사실상 **줌 레벨**
- `latitudeDelta` : 화면 위아래로 위도 몇 도만큼 보여줄지
- `longitudeDelta` : 화면 좌우로 경도 몇 도만큼 보여줄지
- **숫자 클수록 넓게 보임 (줌아웃), 작을수록 좁게 보임 (줌인)**

| **대충 감 잡기** (위도 1도 ≈ 111km)

| span | 대략 보이는 범위 |
|---|---|
| 0.005 | 동네 골목 수준 |
| 0.01 | 동네 하나 (약 1km) |
| 0.05 | 구 하나 정도 |
| 0.5 | 서울 전체 |
| 5 | 한반도 |

# Marker
➡️ 지도에 찍는 **애플 기본 핀**. 풍선 모양에 아이콘이나 글자 들어감

```swift
Map {
    Marker("집", systemImage: "house.fill", coordinate: home)
        .tint(.orange)
}
```

- 모양은 정해져 있고 색, 아이콘, 글자 정도만 바꿀 수 있음
- 지도 확대/축소해도 크기 그대로 유지되고 애플 지도 앱이랑 똑같이 생김
- 빠르게 위치만 표시하고 싶을 때 씀

# Annotation
➡️ 지도 특정 좌표에 **내가 만든 SwiftUI 뷰**를 그대로 올리는 것

```swift
Map {
    Annotation("우리집", coordinate: home) {
        Image(systemName: "pawprint.fill")
            .padding(6)
            .background(.yellow)
            .clipShape(Circle())
    }
}
```

- 클로저 안에 아무 뷰나 넣을 수 있어서 모양 자유롭게 만들 수 있음
- 프로필 사진 핀, 가격 표시 말풍선 (에어비앤비처럼) 이런거 만들 때 씀

## Marker vs Annotation 차이

| | Marker | Annotation |
|---|---|---|
| 모양 | 애플 기본 풍선 핀 고정 | 내가 만든 뷰 아무거나 |
| 커스텀 | 색, 아이콘, 텍스트 정도 | 자유 |
| 코드 | 한 줄이면 끝 | 뷰 직접 만들어야함 |
| 언제 | 그냥 위치만 표시 | 디자인 들어간 핀 필요할 때 |

👉 한 줄 정리 : **Marker는 기성품 핀, Annotation은 내가 직접 만드는 핀**

+ UIKit(MKMapView)에서는 용어가 좀 다름. 거기서는 `MKAnnotation`이 "이 좌표에 뭐 있음" 이라는 **데이터**고, 그걸 그리는 **뷰**가 `MKMarkerAnnotationView`(풍선핀) / `MKAnnotationView`(커스텀) 이렇게 따로 나뉘어 있음. SwiftUI에서는 데이터랑 뷰가 합쳐져서 Marker / Annotation 으로 바로 쓰는 느낌임
