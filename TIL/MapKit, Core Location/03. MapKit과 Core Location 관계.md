# MapKit과 Core Location 관계
➡️ Core Location이 **위치 알아내고**, MapKit이 그걸 **지도에 그려줌**. 둘이 같이 써야 "지도에 내 위치 표시" 가 완성됨

```
[GPS, Wi-Fi, 기지국]
        ↓
  Core Location  →  CLLocation (위치 데이터)
        ↓  .coordinate
  CLLocationCoordinate2D
        ↓
     MapKit  →  지도 화면 (center 이동, Marker 표시)
```

---

.

.

## Q1. MapKit과 Core Location은 각각 어떤 역할을 하는가?
- **Core Location** : 위치를 **알아내는** 역할. GPS, Wi-Fi 같은거 써서 지금 위도 경도, 속도, 방향 같은 데이터 뽑아줌. 권한 관리도 여기서 함
- **MapKit** : 위치를 **보여주는** 역할. 좌표 받아서 지도 띄우고, 핀 찍고, 경로 그림

👉 내비로 치면 Core Location은 **GPS 수신기**, MapKit은 **화면**

.

## Q2. MapKit만 사용해서 사용자의 현재 위치를 알아낼 수 있을까?
처음엔 MapKit은 지도만 그리니까 당연히 안 된다고 생각했는데, 찾아보니까 좀 애매함

- MapKit에도 내 위치 파란점 띄우는 기능 있음
  - MKMapView → `showsUserLocation = true`
  - SwiftUI Map → `UserAnnotation()`
- 근데 이거 **MapKit이 직접 위치 알아내는게 아니라 내부적으로 Core Location 가져다 쓰는 것**임
- 그리고 **권한 요청은 MapKit이 안 해줌**. `CLLocationManager`로 권한 따로 받아야 파란점 뜸. 권한 없으면 `showsUserLocation` 켜도 아무것도 안 뜸
- 파란점은 보여줄 수 있어도 정확도 조절, 백그라운드 위치, 위치 바뀔 때마다 내 코드 실행하기 이런건 MapKit으로 못 함

👉 결론 : **MapKit만으로는 안 됨.** 화면에 파란점 띄우는건 되는데 그것도 결국 뒤에서 Core Location이 일하는거고 권한도 Core Location으로 받아야함. 위치를 **알아내는 주인**은 무조건 Core Location

.

## Q3. Core Location에서 얻은 위치 정보는 MapKit에서 어떻게 활용할 수 있을까?
`CLLocation` 받으면 거기서 `.coordinate` 꺼내서 MapKit한테 넘기면 됨

1. **지도 중심을 내 위치로 옮기기**
   ```swift
   position = .region(MKCoordinateRegion(
       center: location.coordinate,
       span: MKCoordinateSpan(latitudeDelta: 0.01, longitudeDelta: 0.01)
   ))
   ```

2. **내 위치에 핀 찍기**
   ```swift
   Marker("내 위치", coordinate: location.coordinate)
   ```

3. **주변 장소 검색 기준점으로 쓰기**
   - `MKLocalSearch` 요청할 때 region을 내 위치 중심으로 주면 "내 주변 카페" 검색됨

4. **경로 찾기 출발지로 쓰기**
   - `MKDirections` 출발지에 내 위치 넣고 도착지까지 경로 그림

5. **이동 경로 선으로 그리기**
   - 위치 계속 받아서 좌표 배열에 쌓은 다음 `MapPolyline`으로 이으면 러닝앱처럼 지나온 길 표시됨

+ `horizontalAccuracy` 값으로 `MapCircle` 그리면 "대충 이 범위 안에 있음" 오차 원도 표시 가능 (애플 지도 파란점 주변 연한 원이 이거)

.

## Q4. CLLocationCoordinate2D가 MapKit과 Core Location 모두에서 자주 등장하는 이유는?
- 원래 `CLLocationCoordinate2D`는 **Core Location 소속** 타입임 (CL = Core Location)
- MapKit은 좌표 타입 새로 안 만들고 **Core Location 거 그대로 가져다 씀**. 그래서 `import MapKit` 만 해도 CoreLocation 같이 딸려와서 CL 타입 쓸 수 있음
- 결국 둘 다 **"지구 위 어느 한 점"** 을 다루는 프레임워크라서 공통 단위가 필요함
- 같은 타입 쓰니까 Core Location이 준 좌표를 **변환 없이 바로** MapKit에 꽂을 수 있음

👉 두 프레임워크 사이 **공용 언어**같은 거. Core Location이 `CLLocationCoordinate2D`로 말하면 MapKit도 그걸 그대로 알아들음

# 다음 과제 흐름 미리 정리
1. Info.plist에 `NSLocationWhenInUseUsageDescription` 추가
2. `CLLocationManager`로 권한 요청 (`requestWhenInUseAuthorization`)
3. 권한 상태 delegate로 확인 → 허용이면 위치 요청, 거부면 설정 안내
4. `didUpdateLocations`에서 `CLLocation` 받기
5. `.coordinate` 꺼내서 `Map` 카메라 이동 + Marker 표시
