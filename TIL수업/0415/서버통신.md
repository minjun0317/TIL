# 서버 통신

➡️ 서버 = 눈에 보이는 것 , 어드민 자체로서는 안보임<br>
즉, 가공된 데이터들을 사용하는 곳이 서버

## DB(데이터 베이스)

➡️ 정보들의 집합<br>
➡️ 데이터들을 가공한 상자 <br>
➡️ 정보를 넣는거 만으로도 데이터 베이스가 됨

- 데이터를 저장할 수 있는 공간을 만들어 줘야되는데 그 공간이 데이터베이스이다
- 고유의 데이터를 데이터 베이스에 저장

.

||데이터 베이스는 기준을 만들어서 저장||

|비둘기사랑남|옥돼지|박거인|
|남자|여자|남자|
|17세|17세|17세|

- 서버통신을 안해도 사용자가 채팅처럼 보이게 디스플레이를 구현 가능하다
