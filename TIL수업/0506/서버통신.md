## 요청 (request)

DB는 제목, 내용, 날짜 3가지 요소 저장

제목:똥강아지
key:value(type = string)
날짜:0506
key:int

응답을 받아야 DB에 저장된 값을 볼 수 있음
디코딩으로 응답(디코딩 = 다른언어로 변환) 서버언어 -> swift 언어

디코딩 할 때 json을 거침, 서버 -> json -> swift

json의 구성요소 - key : value

DB 베이스 저장값 -> json(key:value) -> swift

서버에서 똥강아지란 값(object c)을 클라이언트로 안보내고 왜 서버에서 string이라는 자료형(swift)으로 보낼까

- swift는 타입추론이 가능함, 서버에서 필요한 타입을 클라이언트가 같은 타입을 지정함
