**<컬렉션 타입>**<hr>
-
*
컬렉션 = 여러 개의 데이터를 한 번에 담아두는 상자
*
<span style="color:red">Array, Dictionary, Set</span>

**<'Array'>**<hr>
-
*
순서가 있는 리스트 컬렉션
*
요소를 맨 뒤에 추가하고 싶으면 : append
*
가지고 있는지 확인하려면 : contains
*
인덱스 삭제하려면 : remove
*
개수 확인하려면 : count
<br><span style="red">Array(Double) = ['Double']</span><br>
*
let를 사용해 선언하면 불변 Array


**<'Dictionary'>**<hr>
-
*
키(값을 찾기 위한 이름표)와 값의 쌍으로 이루어진 컬렉션
*
인덱스를 삭제하려면 : removeValue, nil

**<'Set'>**<hr>
-
*
순서가 없고, 멤버(각각의 값, 즉 요소)가 유일한 컬렉션, 얘만 축약이 없음
*
요소를 추가하고 싶으면 : insert
*
인덱스 삭제하려면 : remove
*
개수 확인하려면 : count
<br><span style="color:red">union(합집합), sortedUnion(정렬 합집합), intersection(교집합), subtracting(차집합)</span>
