**<매개변수 기본값>**<hr>
-
*
기본값을 갖는 매개변수는 매개변수 목록 중에 뒤쪽에 위치하는 것이 좋음
*
매개변수 기본값을 가지는 매개변수는 생략할 수 있슴
<br>
*
func 함수이름(매개변수1이름: 매개변수1타입, 매개변수2이름: 매개변수2타입 = 매개변수 기본값 ...) -> 반환타입{

return 반환값
}

-
*
전달인자 레이블은 함수를 호출할 때
*
매개변수의 역할을 좀 더 명확하게 함
*
함수 사용자의 입장에서 표현하고자 할 때 사용함
*
함수 내부에서 전달인자를 사용할 때에는 매개변수 이름을 사용함
*
함수 내부에서 전달인자를 사용할 때에는 매개변수 이름을 사용해야 함

*
func 함수이름(전달인자 레이블 매개변수1이름: 매개변수1타입, 전달인자 레이블 매개변수2이름: 매개변수2타입 ...) -> 반환타입 {

**<데이터 타입으로서의 함수>**<hr>
-
*
스위프트는 함수형 프로그래밍 패러다임을 포함하는 다중 패러다임 언어임
<br>
함수형 프로그래밍 = 함수를 값처럼 사용하며, 상태변화를 최소화하고, 같은 입력을 받아 항상 같은 결과가 나오게 하는 프로그래밍
패러다임 = 프로그래밍 방식/스타일
<br>
그래서 여러 프로그래밍 방식이 가능한 언어인데 그중에 함수형 프로그래밍도 지원한다는 뜻

**<함수의 타입표현>**<hr>
-
*
반환타입을 생략할 수 없음 : (매개변수1타입, 매개변수2타입 ...) -> 반환타입
가변 매개변수와 같은 타입이 다른 함수는 할당할 수 없음
