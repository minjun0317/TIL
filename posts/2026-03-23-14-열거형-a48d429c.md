**<열거형>**<hr>
-
*
enum은 타입이므로 대문자 카멜케이스를 사용하여 이름을 정의함
*
각 case는 소문자 카멜케이스로 정의함
*
각 case는 그자체가 고유의 값으로 취급
*
정의 = enum 이름 {
case 이름1
case 이름2
case 이름3, 이름4, 이름5
...
}
<br>
*
C언어의 enum처럼 정수값을 가질 수도 있음
rawValue를 사용하면 됨
case별로 각각 다른 값을 가져야 함
*
정수 타입뿐만 아니라 Hashable 프로토콜을 따르는 모든 타입이 원시값의 타입으로 지정 될 수 있으

**<원시값을 통한 초기화>**<hr>
-
*
rawValue를 통해 초기화
rawvalue가 case에 해당하지 않으므로 옵셔널 타입
