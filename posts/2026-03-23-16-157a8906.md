클로저(Closure) = 이름없는 함수(익명 함수) 
*
변수에 저장하거나 다른 함수에 전달 가능
<br>

기본 형태
{ (매개변수) -> 반환타입 in
    실행코드
}

함수와 차이
*
클로저는 주변 값(외부 변수)을 캡처해서 사용 가능
let num = 10
let closure = { print(num) } // num을 기억함
*
점점 축약 가능 (스위프트 특징)
<br>

자주 쓰는 이유 
*
정렬,비동기 처리, 콜백 등에서 코드 간단하게 전달하려고

핵심 한줄: 클로저 = 코드 블록을 값처럼 저장·전달하는 기능
