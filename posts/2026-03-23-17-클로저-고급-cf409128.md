**<값 캡처(Capturing Values)>**<hr>
-
클로저는 외부 변수 값을 기억함 
*
함수 끝나도 값 유지됨
호출할 때마다 count가 계속 증가
<br>

Escaping / Non-escaping 클로저
함수 끝난 뒤에도 실행되면 @escaping 필요 
*
비동기에서 자주 사용
나중에 실행될 가능성 있으면 escaping
<br>

클로저 캡처 리스트 (메모리 관리)
*
참조 타입(class) 사용할 때 강한 순환참조 방지

weak, unowned 사용해서 메모리 누수 방지
<br>

*
Trailing Closure (후행 클로저)
마지막 매개변수가 클로저면 밖으로 빼서 가독성
func work(action: () -> Void) { action() }
<br>

*
자동 축약 문법
타입 추론 + shorthand argument
클로저 = 값을 기억하고, 나중에 실행할 코드를 전달하는 도구 (특히 비동기 콜백에서 필수)
