*
상속(Inheritance) =기존 클래스의 특성(프로퍼티,메서드)을 물려받는 것
*
class만 가능 → struct, enum은 상속 없음
*
부모 클래스 = 슈퍼클래스 / 자식 클래스 = 서브클래스
*
자식 클래스는 기능 추가하거나 수정(재정의, override) 가능
*
코드 재사용 + 구조 정리에 좋음
<br>

상속 = 부모 기능 물려받고 필요한 부분만 바꿔 쓰기
