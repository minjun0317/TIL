*
고차함수(Higher-Order Function) = 함수를 값처럼 사용하는 함수
*
함수를 매개변수로 받거나, 함수 실행 결과로 함수를 반환
*
컬렉션(Array 등)의 데이터 처리 간단하게 해줌
*
대표 예시 개념
 - map - 각 요소를 변환
 - filter - 조건에 맞는 것만 선택
 - reduce - 모든 요소를 하나의 값으로 합침
*
반복문보다 코드가 짧고 읽기 쉬움
<br>
