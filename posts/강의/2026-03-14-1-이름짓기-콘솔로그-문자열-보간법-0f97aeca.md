**이름 규칙**<hr>
-
*
Lower Camel Cace(소문자) : fuction, method, variable, constant
<span style="color:orange">Ex)someVariableName</span>

*
Upper Camel Cace(대문자) : type(class, struct, enum, extension...)
<span style="color:orange">Ex)Person, Point, Week</span>

*
대소문자를 구분하는 명령어

**콘솔로그**<hr>
-
콘솔로그 = 프로그램이 실행되는 동안 상태나 값(변수값), 오류(디버깅) 등을 화면(콘솔)에 출력해서 확인하는 기능
*
print : 단순 문자열 출력
*
dump : 인스턴스의 자세한 설명(description 프로퍼티)까지 출력

인스턴스 = <span style="color:orange">실제로 만들어진 객체(실체), 즉 설계도에서 실제물건 같은 관계</span>

description = <span style="color:orange">어떤 객체를 문자열로 표현한 값
  
**문자열 보간법**<hr>
-
문자열 보간법 = 프로그램 실행 중 문자열 내에 변수 또는 상수의 실질적인 값을 표현하기 위해 사용
*
\() 괄호 사이에 값을 넣어주면 문자열에서 자동으로 치환해서 나타냄
