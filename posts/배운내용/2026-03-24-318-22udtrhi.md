**<객체 지향 프로그래밍(OOP)>**<hr>
-
*
현실 세계에 가까운 방식으로 프로그래밍하는 것(그래서 OOP는 모든 것을 객체로 바라봄)
*
객체 = 데이터와 그 데이터 관련된 메서드를 하나로 합친 것
*
코드의 재사용성과 유지보수성을 향상시키고, 여러 유형의 객체가 있는 복잡한 시스템을 개발할 때 확장성을 개선하는데 뛰어남

## 클래스 & 객체 (기본)

- 클래스: 설계도
- 객체: 실제 생성된 인스턴스

*
클래스 vs 객체 vs 인스턴스 차이

클래스 = 설계도
객체 = 설계도로 만든 결과물
인스턴스 = 클래스로 만든 실제 메모리 존재 객체
*
Swift에서 OOP가 쓰이는 곳

class
protocol

객체지향 프로그래밍(OOP)은 현실 세계의 사물을 객체로 표현하여 프로그램을 구조적으로 설계하는 방식이다. 클래스는 객체를 만들기 위한 설계도이며, 객체는 해당 클래스를 기반으로 생성된 실제 데이터이다. 객체는 속성(Property)과 행동(Method)을 가지며, 이를 통해 코드의 재사용성과 유지보수성을 높일 수 있다. 객체지향의 주요 특징으로는 캡슐화, 상속, 다형성, 추상화가 있으며, 이러한 특징을 통해 유연하고 확장 가능한 프로그램을 만들 수 있다.
